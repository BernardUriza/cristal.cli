# CRISTAL.CLI

Live: https://cristal.bernarduriza.com

Two games on one procedural art engine, in the browser.

- **Labyrinth** (`/laberinto.html`): an occult-terminal narrative game in Three.js. You walk a maze, find consoles and type what you feel. Rooms are generated by an AI oracle with a seeded local fallback, so the descent never stalls.
- **Memorama** (`/memorama.html`): a memory game whose cards are neobaroque temples, drawn from a vector grammar (columns, domes, arches, mosaics) deterministically from a seed. No two games share their art. Plays on a phone.

CRISTAL is a narrative interface, not an operating system. Its purpose is to provoke the player to write what they *feel*, not what they *know*.

## How it works

- **Art engine** (`web/src/graphics/`): a grammar in meters → projection → display list → SVG, Canvas 2D or Three.js textures. Zero AI-generated images; every column, dovela and rosette comes from geometry and a seed. Layering is enforced by a test.
- **Labyrinth** (`web/src/game/`): React Three Fiber port of the Unity original. Pure, deterministic rule modules (maze, stability, pressure, transference) with tests next to them; the R3F layer only renders.
- **Memorama** (`web/src/memorama/`): pure rules (seeded deal, flip, resolve, win) plus a per-card art config derived from the pair seed. The seed and pair count live in the URL, so a game is shareable and replayable.
- **API** (`server/`): FastAPI on Azure Container Apps. `/generate` writes rooms with Claude through AIRE; `/tarot/*` serves the sibling project [tarot-thoth](https://github.com/BernardUriza/tarot-thoth).

## Stack

TypeScript, React 18, React Three Fiber, three.js, Vite, Vitest, Zustand. Python, FastAPI. Azure Static Web Apps (front) and Azure Container Apps (API), deployed from GitHub Actions on every push to `main`.

## Run it locally

```bash
cd web
npm install
npm run dev        # http://localhost:5173 — selector, /laberinto.html, /memorama.html
npm test           # vitest
npm run typecheck
```

The labyrinth talks to `VITE_CRISTAL_LLM_URL` (default `http://localhost:8131`, see `server/run.sh`). Without the API it falls back to local rooms.
